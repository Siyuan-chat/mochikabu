SYNTHETIC CASE STUDY

奨励金 10% なら、持株会を増額すべき？

結論を「奨励金が高いから増額」で終わらせず、会社の評価、本人負担取得費用、同業比較、資産集中まで順番に確認する例です。

このページの数値・会社・制度はすべて架空です。 判断フローの説明用であり、実在企業への投資判断ではありません。

1. まず制度だけを見る

項目 架空条件
市場株価 ¥5,000
奨励金率 10%
現在の月額拠出 ¥30,000
候補 ¥30,000 / ¥50,000 / ¥70,000

税や手数料を無視した単純化では、10% の奨励金が付くと本人負担ベースの取得コストは市場株価より低くなります。

PersonalPurchaseCost = MarketPrice / (1 + EffectiveIncentive)
¥5,000 / 1.10 ≈ ¥4,545

ここだけなら「有利」に見えます。しかし、これだけでは増額を決めません。

2. 次に会社そのものを評価する

架空の公開財務情報から DCF 中心値が ¥4,600、感応度レンジが ¥4,100–¥5,200 だったとします。市場株価 ¥5,000 は中心値を約 8.7% 上回ります。

一方、奨励金調整後の本人負担取得コスト約 ¥4,545 は DCF 中心値に近くなります。つまり「市場ではやや割高でも、制度を通した本人負担では評価が変わる」という状態です。

3. DCF だけで決めない

同業比較で対象会社が peers より高い PER / PBR を持つ場合、そのプレミアムが成長率や収益性で説明できるかを確認します。DCF と相対評価を一つの数値に混ぜず、食い違いを残します。

4. 最後に、勤務先への集中を見る

持株会では給与・賞与・キャリアと金融資産が同じ会社に依存しやすくなります。すでに金融資産の大きな割合を勤務先株式が占めるなら、奨励金があっても追加増額が最適とは限りません。

5. 結論は条件付きになる

「10% 奨励金だから増額」ではなく、「奨励金込みの取得コストは魅力的だが、評価プレミアムと集中度を確認してから増額幅を決める」が適切な表現になります。

なぜこの設計なのか

持株会では「会社は良いか」「株価は高いか」「制度は有利か」「自分の資産配分に合うか」が別の問題です。Mochikabu はこの四つを混ぜず、最後に同じ意思決定へ接続します。
