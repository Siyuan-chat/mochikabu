# Independent extraction acceptance

Ordinary valuations and calculation regressions run in one chat using the installed scripts. Start two independent analysts only when the user explicitly requests an independent test.

1. The coordinator fixes a common market date and collects original issuer, peer and market documents in a case-specific evidence directory. Use scripts/fetch_public.py for report collection. Use one canonical official URL per publication. Repeated collections into this directory reuse verified original bytes. The coordinator is the only writer and adds missing originals on request. Both analysts can read originals/ and its source receipts. Keep generated extracts, earlier decisions and filled financial or market files outside their inputs.
2. Run scripts/prepare_extraction_trial.py INSTALLED NEW_CASE for each analyst. Give each the same original question, the shared source directory and its own empty work directory. Send the fixed reply from tests/fixtures/contribution-dialogue.json after each analyst asks, without asking the user. Independent readers select the model, transcribe observations and run the installed runner separately.
3. Invoke scripts/compare_extractions.py A B AUDIT --inputs-only for transcription checks before completed valuations, or omit --inputs-only to include stable FCFF, per-share bounds and decisions. Read summary.json for normalized field keys and market differences. Use fields.csv for other inputs such as model selection, project timing and personal facts. Different source wording, URLs or record order alone do not require financial rereading.
4. For each substantive difference, identify the exact period, field, original row, column, scope and unit. Reopen only that source and any directly related reconciliation rows. Preserve the initial outputs. Correct affected fields in a copy, run the affected validation and deterministic calculation, and compare the corrected outputs. A corrected replay is reported as a replay. Do not start new agents, redownload unchanged filings or restart a blind round unless the user specifically requests a fresh round.
